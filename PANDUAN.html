PORTAL HUB · PETUNJUK PEMASANGAN

Dari GitHub,
terhubung ke Supabase.

Alamat proyek dan publishable key sudah diisi. Ikuti empat langkah berikut untuk mengaktifkan portal.

Paket kode sudah siap. Database, akun admin, dan GitHub Pages perlu diaktifkan melalui akun Anda. File panduan ini tidak membuat perubahan apa pun tanpa tindakan Anda.

1Buat tabel portal

  1. Buka proyek Supabase menggunakan tombol di bawah.
  2. Pilih SQL Editor, lalu buat query baru.
  3. Salin SQL pemasangan, tempel ke editor, kemudian jalankan seluruhnya.
Buka proyek Supabase ↗Unduh file SQL

Lihat SQL pemasangan

SQL menggunakan tabel berawalan hub_portal_ dan tidak mengubah tabel aplikasi lain.

2Aktifkan akun admin

  1. Di Supabase, buka Authentication → Users.
  2. Buat akun menggunakan email dan password Anda, atau gunakan akun yang sudah ada. Pastikan email akun dikonfirmasi.
  3. Isi email yang sama pada kotak di bawah, lalu salin SQL aktivasi.
  4. Jalankan SQL tersebut di SQL Editor. Password akun tidak dimasukkan dalam SQL.

Lihat SQL aktivasi admin

Tidak ada password bawaan. Untuk akun anggota tim, gunakan petunjuk pada tambahkan-anggota.sql.

3Upload ke repository GitHub

  1. Ekstrak paket ZIP yang diterima.
  2. Buka repository tujuan, lalu Add file → Upload files.
  3. Upload seluruh isi folder, termasuk docs beserta docs/assets, kemudian commit.
Buka repository GitHub ↗

4Aktifkan GitHub Pages

  1. Di repository, buka Settings → Pages.
  2. Pilih Deploy from a branch.
  3. Pilih branch main dan folder /docs, lalu klik Save.
  4. Tunggu proses selesai, lalu buka URL website yang ditampilkan GitHub.
  5. Klik Masuk portal dan gunakan akun yang sudah diaktifkan pada langkah 2.
Folder yang diterbitkan adalah /docs. File docs/index.html dan asetnya sudah dibangun, sehingga pemasangan awal tidak memerlukan npm.
Data link, kategori, dan pengumuman disimpan pada Supabase. Favorit dan riwayat disimpan di browser masing-masing. Baca README.md untuk pengembangan dan cadangan data.
